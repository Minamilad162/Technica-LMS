# P34 — Admin One-Save Lesson Quiz and Selected Mock Test

**Owner decision:** Question Bank is the single source for Course Questions. Admin imports questions, chooses Difficulty / Active / Mock Exam / Lesson Quiz, and clicks **Save All Changes once**. No separate "Review Draft Questions" step is required to make **Lesson Quiz** selections appear to eligible Learners. The previously linked 2 unpublished Lesson 1 questions can be released in one Save from the per-Lesson Admin status strip. Selecting **Mock Exam** sends qualifying candidates to an independently accessible **Selected Mock Test**. The existing **Official ASP Mock 200/300** and its P9B immutable reservation remain separate and unchanged.

## Data/security and preservation

Migration **P34A** `supabase/migrations/202611080005_p34a_one_save_lesson_quiz.sql` (source only) adds `lms_p34_lesson_releases` as an Admin-authenticated, Lesson-specific release receipt. Secure `lms_p34_save_question_bank(course_uuid,changes_json,optional_lesson_uuid)` delegates to the guarded P30 one-transaction save, then publishes new Lesson references and optionally all **eligible** existing unpublished links for one selected Lesson. Receipt is per `quiz_question_id + lesson_id + bank_question_id`, not a global `lms_questions.approval_state` change. DRAFT remains DRAFT for Practice/Level Up; P4/P8e selectors still require approved and reject mock-only. Mock-exclusive, Mock candidate, disabled, archived, wrong-Course, malformed and over-length questions remain forbidden in Lesson Quiz. Disabling questions unpublishes existing Quiz entries. Admin-only direct `lms_p34_publish_lesson_quiz` enables the Course Builder Publish action. SQL installation does **not** publish any existing questions; publication requires an explicit Admin Save or Publish.

Migration **P34B** `supabase/migrations/202611080006_p34b_selected_mock_engine.sql` (source only) adds isolated selected-Mock attempts and frozen server-side answer snapshots. Only Active, Draft, Mock-candidate, non-official, unlinked, unused-in-Practice questions qualify. Learners with verified access can launch the separate 300-minute Selected Mock Test, answer/flag, submit and receive **server-graded scores**, with fullscreen protection and no answer keys sent to browser. Selection count may be below 200; each attempt uses at most 200 selected items. Official ASP Mock P9B/P10 remains the separate fixed 200-question exam, unchanged by Admin's Selected Mock flag.

Frontend: `AdminCourseBank.jsx` uses the P34A/P34B capability handshakes; without both migrations, new edit/save controls stay disabled rather than failing silently. One Save request is atomic (maximum 500 changed questions), can additionally release old pending Lesson links via a single checkbox. `LiveMockPortal.jsx` defaults to Selected Mock Test and retains an Official ASP 200 switch; `LiveSelectedMockExam.jsx` reuses secured timer/fullscreen UX. `AdminLessonQuizEditor.jsx` can publish a linked Draft through the narrowly scoped P34 RPC. Learner `CourseLessonExplorer.jsx` keeps Video → Study Material → Quiz, scrolling to Quiz on top shortcut.

## Release discipline

1. Before any real Supabase write, inspect actual target project ID and read-only migration ledger, P1/P22/P28.2/P29/P30 prerequisites, foreign-key/type signatures and backups. Do not replay an already-installed migration, manually change official P9B items, import historical ASP questions, or execute the disposable CI smoke against production.
2. Apply **P34A followed by P34B** *only* after authorized target/backup/ledger checks. These are not auto-applied by merge/deploy. Verify new SQL RPCs via Admin capability checks; no user data should be changed by installation.
3. As verified Admin, choose an eligible source question and Lesson 1, Save once. Learner refreshes same Lesson Quiz and sees it. For the previously linked 2 unpublished questions, choose Lesson 1, tick `Publish saved Lesson questions` and Save once.
4. On another unused Draft choose Mock and Save; verified Learner opens Assessments → Selected Mock Test, starts the timed attempt and completes one server-graded answer. Confirm old Official ASP 200 still intact.
5. Confirm invalid cross-Course / Mock-vs-Lesson / disabled / stale data is rejected, do not disclose correct answers in API payload, and no enrolled data is changed by migration install.
6. CI: `npm run test:p34:one-save`, `bash scripts/test-p34-postgres-smoke.sh` on ephemeral Postgres, existing P1–P33 security suites, React build. Release requires green PR checks and Cloudflare build. Verify real deployment separately; never label remote DB migrated without evidence.

**Important distinction:** This removes an *extra approval UI step for Lesson Quiz and Selected Mock release only*, not the P6A rights/quality approval rules that already exist for standard Practice/Level Up or the immutable official ASP exam. Selected Mock and Official ASP Mock are intentionally separate to avoid changing official exam inventory.
