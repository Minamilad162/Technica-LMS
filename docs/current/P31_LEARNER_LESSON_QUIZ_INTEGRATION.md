# P31 — Question Bank → Learner Lesson Knowledge Check

## Owner requirement
After an Admin saves a Question Bank row with a selected Lesson Quiz, that question belongs to exactly the selected Lesson in the canonical Course → Domain → Topic → Lesson hierarchy. A subscribed/eligible learner sees the published question in the **Knowledge Check/Quiz section of the same Lesson page**, below Video and Study Material (which includes PDF attachments). Tapping **Knowledge Check** in the sticky jump navigation scrolls to the quiz; it never switches pages or hides Video/Material. No answer key is sent to the browser.

## Existing and verified design
- P30 atomic Admin Save calls the P28 secure attach RPC once for each newly chosen Lesson link. Existing backend checks Course ownership, status, Mock-only exclusion, duplicate links, and position. If the bank question's `approval_state='approved'`, the Quiz row is **published at attach**. If **draft**, it is linked but **unpublished** and cannot appear to learners without independent approval plus explicit publication from Course Builder → Lesson Quiz. No auto-approval of the ASP 2500-question bank.
- P22 learner `lms_p22_get_lesson_quiz(lesson_uuid)` is the authority: entitlement/free-intro checks, active profile, `is_published=true`, only `id/prompt/options` returned. The correct answer stays inside secure `lms_p22_submit_lesson_quiz` and is never exposed by the Admin Bank response. The actual learner route `LiveLearnerWorkspace` already mounts `CourseLessonExplorer` with actual Course/outline/user, and one Lesson page already mounted Video → Material → Quiz.
- P31 strengthens loading and navigation. A dedicated `lessonQuizSyncApi.js` validates the published learner payload, supports Admin-only preview of Draft links without correct answers, and rejects malformed/duplicate/answer-key-leaking records. `CourseLessonExplorer` loads the P22 list on Lesson selection and refreshes it when learners click Knowledge Check (or use Refresh questions), without remounting media. If clicked while loading, the target is remembered and scrolled into view once available. The quiz tab shows a true current-Lesson published question count. On changed published question IDs, old answer selections and stale result are cleared; re-quiz submission remains P22 server-graded.
- Admin Save notification explicitly reports approved links published to learners versus Draft links awaiting independent approval and publication. No SQL migration is needed for P31 on a DB that already has the required P22/P28/P29/P30 source migrations; no migrations or live data are applied by merging this PR.
